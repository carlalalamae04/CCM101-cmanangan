# Reflection

This laboratory was my first experience working with a Linux environment through KillerCoda. At first, I was a little confused with some of the commands and how the terminal worked, but as I followed the steps, I slowly became more comfortable using it.

I learned how to create a new user, log in to the account, and check basic information about the system. I also learned how to find the Linux version, kernel version, CPU information, memory, and available disk space. Creating folders and Markdown files through the terminal also helped me understand how Linux manages files and directories.

Another thing I learned was how to organize my work using GitHub. I created my Cloud Computing Portfolio and learned that I can use it to keep my laboratory activities, screenshots, and documents organized in one place.

This activity helped me become more familiar with Linux and cloud-based environments. I made some mistakes while doing the activity, but those mistakes also helped me understand the commands better. I know there are still many things I need to learn, but this laboratory gave me a good starting point for learning more about cloud computing.
