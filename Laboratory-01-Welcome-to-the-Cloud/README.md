# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduced me to a cloud-based Linux environment using KillerCoda. I explored the Linux terminal, created a new user account, gathered basic system information, organized files and folders, and prepared a GitHub repository for my Cloud Computing Portfolio.

## Objectives

* Access and use a Linux environment through KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Create and organize files and directories using Linux commands.
* Create a GitHub repository for my cloud computing portfolio.
* Practice documenting technical activities using Markdown.

## Activities Performed

* Accessed the Ubuntu Linux Playground using KillerCoda.
* Created a new Linux user account with a home directory, Bash shell, and sudo privileges.
* Logged in to the new user account.
* Checked the current username, working directory, and hostname.
* Gathered information about the Linux distribution, kernel, CPU, memory, and disk space.
* Created and organized the required folders and files.
* Created an `about-me.md` file inside the Notes folder.
* Prepared a GitHub repository for the Cloud Computing Portfolio.
* Documented the laboratory activities using Markdown.

## Linux Commands Used

* `whoami` – displays the current username.
* `pwd` – displays the current working directory.
* `hostname` – displays the hostname.
* `su` – switches to another user account.
* `useradd` – creates a new user.
* `usermod` – modifies a user account.
* `passwd` – sets or changes a user's password.
* `mkdir` – creates directories.
* `cd` – changes the current directory.
* `ls` – lists files and directories.
* `cat` – displays the contents of a file.
* `nano` – creates or edits text files.
* `cat /etc/os-release` – displays Linux distribution information.
* `uname -r` – displays the kernel version.
* `lscpu` – displays CPU information.
* `free -h` – displays memory information.
* `df -h` – displays disk space information.
