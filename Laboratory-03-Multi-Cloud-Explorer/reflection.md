# Mission 3 Reflection

After completing Mission 3, I learned more about AWS, Microsoft Azure, and Google Cloud Platform and how they can be used for different business needs. The cloud platform that impressed me the most was Google Cloud because of its support for artificial intelligence, machine learning, and Kubernetes. I also learned that each cloud provider has its own strengths even though many of their services are similar. Comparing the three platforms helped me understand that choosing a cloud provider depends on more than just the number of services it offers.
AWS, Azure, and GCP have several similarities. All three provide services for virtual machines, storage, databases, networking, and identity management. They also allow organizations to use scalable cloud infrastructure without having to manage all of the physical hardware themselves. Because of these similarities, businesses can compare the providers based on their specific requirements. I also learned that similar services can have different names depending on the cloud provider.
Business requirements are important when selecting a cloud platform. A company should consider its budget, existing technology, workload, scalability, security needs, and technical skills. For example, Azure can be a good choice for an organization that already uses Microsoft technologies, while Google Cloud can be suitable for organizations that focus on artificial intelligence and Kubernetes.
Acting as a Cloud Solutions Consultant taught me that there is no single cloud provider that is always the best choice. The best platform depends on the client's specific requirements and the problem that needs to be solved. Comparing the four client scenarios helped me understand how technical decisions should be connected to business needs. The KillerCoda activity also helped me connect a Linux server to cloud virtual machine services.
