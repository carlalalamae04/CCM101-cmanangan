# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, databases, networking, identity, artificial intelligence, analytics, and application development.

## Global Infrastructure

Azure provides cloud infrastructure through geographically distributed regions and data centers. This allows organizations to deploy applications in different locations and improve availability.

## Cloud Management Console

The Azure Portal is a web-based management interface for Azure. It allows users to create, configure, monitor, and manage Azure resources and services.

## Four Core Services

1. **Azure Virtual Machines** – A compute service used to run virtual machines in the cloud.
2. **Azure Blob Storage** – A storage service used to store large amounts of unstructured data.
3. **Azure SQL Database** – A managed relational database service.
4. **Microsoft Entra ID** – An identity service used to manage users, identities, and access.

## Three Advantages

1. Azure has strong integration with Microsoft technologies.
2. Azure supports both Windows and Linux workloads.
3. Azure provides enterprise identity and management services.

## Typical Enterprise Use Cases

Azure can be used by enterprises for:

- Windows Server workloads
- Microsoft 365 environments
- Enterprise applications
- Databases
- Web applications
- Hybrid cloud environments
