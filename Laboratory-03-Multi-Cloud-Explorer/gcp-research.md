# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is Google's cloud computing platform. It provides services for computing, storage, databases, networking, artificial intelligence, analytics, and Kubernetes.

## Global Infrastructure

Google Cloud provides infrastructure through regions and zones located around the world. This allows organizations to deploy applications in different geographic locations.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources. Users can create, configure, monitor, and manage services through the console.

## Four Core Services

1. **Compute Engine** – A compute service used to run virtual machines.
2. **Cloud Storage** – An object storage service used to store data and files.
3. **Cloud SQL** – A managed relational database service.
4.	**Google Kubernetes Engine (GKE)** – A managed Kubernetes service used to deploy and manage containerized applications.

## Three Advantages

1. Google Cloud has strong artificial intelligence and machine learning capabilities.
2. Google Cloud provides strong Kubernetes support.
3. Google Cloud provides scalable global infrastructure.

## Typical Enterprise Use Cases

Google Cloud can be used by enterprises for:

- Artificial intelligence and machine learning
- Data analytics
- Web applications
- Kubernetes applications
- Cloud databases
- Large-scale data processing
