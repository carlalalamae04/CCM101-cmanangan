# Project Overview

This project focuses on developing and deploying a secure multi-tier web application using WordPress and MySQL. It runs on Ubuntu Server through Docker and Docker Compose, allowing the website and database to operate in separate containers.

The project contains a WordPress website, a MySQL database, persistent storage volumes, and a Docker network for communication between services. It also includes security configurations using UFW, a Bash script for database backups, and Cron for scheduling automated backup tasks.

Through this project, we demonstrate the practical use of Docker containerization, database management, data persistence, server security, and backup automation in a Linux environment.
